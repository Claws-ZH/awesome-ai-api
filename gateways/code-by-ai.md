## Pricing | 定价

Pay-as-you-go, billed per token; no subscription, minimum top-up US$3. Larger top-ups get an automatic tiered discount of 3%–15%.

Per-model prices are published on the official models page (https://www.codebyai.net/models) and as public JSON (https://www.codebyai.net/api/model-prices), shown next to each vendor's official list price. The site states token prices from about 1/6 of official prices.

## Supported Models | 支持模型

21 models listed on the official site: 11 Claude, 6 GPT/Codex, 4 Gemini (see the models page for the current list). GPT Image 2.5 image generation is also available with the same key.

## Upstream | 上游来源

Operator disclosure: Claude/GPT/Gemini access is provided through a reverse-engineered channel (逆向).

## Features | 特色功能

- One API key and one prepaid balance across Claude, GPT/Codex and Gemini
- OpenAI-compatible base URL: `https://www.codebyai.net/api/agent/v1`
- Native Anthropic Messages, OpenAI Responses, OpenAI Chat Completions and Gemini formats, forwarded as-is (streaming and tool calls behave as each client expects)
- Setup docs for Claude Code, Codex CLI, Gemini CLI, OpenCode, Cline, Trae, Qwen Code and others
