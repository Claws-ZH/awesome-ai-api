## Pricing

Per-token billing. `actual charge = token usage × model unit price × group multiplier`.

- Input and output tokens are billed **separately** — no blended single rate.
- Group multiplier and model multiplier are both visible in the console.
- Minimum top-up: CNY 10. No forced large prepayment.
- Free credit on signup.

**Honest limitation**: there is currently **no standalone public price page**. Prices live behind login in the console. `/v1/models` requires Bearer auth and returns 401 without a key. A public model-plaza page exists in the codebase but is disabled (`model_plaza_enabled = false`) — enabling it is on the operator's roadmap. I am not going to paste per-model figures here that I cannot verify.

## Features

- Single OpenAI-compatible endpoint covering all model families
- Native Anthropic protocol support — Claude Code works with two env vars
- Open-source Sub2API panel, so per-call token counts and charges are auditable rather than claimed
- Channel monitoring with multi-upstream failover
- Three-layer rate limiting: user-level, token-level (per-key concurrency), and global QPS
- Signup with a QQ mailbox only: no invite code, no phone binding, no foreign card
- Streaming (SSE), tool calling / function calling, vision input, up-to-1M-token context, session stickiness to the same upstream account

## Pros & Cons

**Pros**
- Lowest signup friction among comparable relays — QQ mailbox, ~30 seconds, no invite code
- Input/output billed separately with disclosed multipliers, which is the single most common place relays hide margin
- Open-source panel means billing can actually be checked, not just promised
- Low minimum top-up (CNY 10) makes a trial cheap
- Dual protocol (OpenAI + Anthropic) means one key serves Claude Code, Codex CLI, Cursor and plain SDK calls

**Cons**
- Individually operated, no registered entity or ICP filing visible — **do not prepay large amounts**
- No standalone public pricing page; `/v1/models` requires auth. This will make automated verification harder and is the main reason this entry has no filled price table
- Occasional latency spikes during peak hours; keep a backup route for critical work
- Password reset is not enabled — forgotten passwords require manual admin assistance
- Chinese-language UI only
- Operates a documented acceptable-use policy that forbids scanning/exploitation of third-party assets; legitimate reverse engineering of *your own* binaries is allowed, but the scope is narrower than a general-purpose relay
